# Srinivas Portfolio Videos — Clear Arcade Edition

This revised collection contains 13 silent, 13-second, Full-HD portfolio videos.

## What changed

- Removed the moving white CRT line and the dark scanline overlay.
- Replaced the slide-like mission screens with continuous project animation.
- Added a large `INPUT → PROCESS → OUTCOME` guide to every video.
- Reworked key scenes so that data and objects visibly move through the system.
- Kept the 90s arcade-game visual style while making the project purpose easier to understand.

## Project flows

1. **SmartCap:** vital sensors → cap controller checks readings → live phone dashboard.
2. **GitHub Assistant:** question and repository → code and commits scanned → contextual answer.
3. **Pulmonary Fibrosis:** CT scan and patient data → ResNet analysis → FVC decline forecast.
4. **Nuclei Detection:** microscopy image → enhancement and cleaning → outlined and counted nuclei.
5. **Ceph Cluster:** file enters cluster → copies spread across nodes → file survives a node failure.
6. **Apache Spark:** large dataset → job split across workers → partial results merged.
7. **AGM 3D Tracking:** motion-sensor readings → Python sensor fusion → GPS-free 3D path.
8. **Crocodile Recognition:** new photo → natural patterns compared → individual match identified.
9. **River Sensor:** underwater readings → timestamped logging → data sent remotely.
10. **R Shiny Auto-Start:** Windows starts → script launches both apps → dashboards become ready.
11. **MyMirro Fashion AI:** outfit photo → garment segmentation → digital wardrobe updated.
12. **Network Intelligence:** network and IOPS metrics → degradation and cause predicted → fix starts early.
13. **Manufacturing Agent:** production evidence → delivery bottleneck detected → explainable risk report.
